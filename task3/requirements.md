# Требования для внешних интеграций "Умный дом"

## Общие требования к безопасности
1. Системы не должны работать с ПД пользователей. Им достаточно идентификаторов сущностей (пользователь, шлагбаум и домофон).
2. Данные должны храниться в зашифрованном виде.
3. Системы должны предоставить возможность пользователю управлять своими данными(номера машины, биометрия).

## Протоколы аутентификации и авторизации
1. Использовать OAuth 2.0 для авторизации пользователей через мобильное приложение.
2. Использовать mTLS для аутентификации между tenant-core-app и внешними сервисами.

## Взаимодействие между системами предприятия и внешней платформой
1. Трафик между мобильным приложением и внешней платформой должен быть защищен с помощью TLS.
2. Внешняя платформа должна предоставлять API для взаимодействия через мобильное приложение.
